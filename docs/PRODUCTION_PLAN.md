## Tool routing
- **Codex** (primary): curriculum, evidence-based academic text, structured Word/Markdown, slide drafts, notebooks, solutions in private storage, QA scripts and reusable skills.
- **Microsoft 365 Copilot** (manual handoff): edit/improve approved PPTX visual quality; verify licence features and mathematical fidelity.
- **GitHub Copilot** (optional): coding support for notebook tests, build scripts, GitHub Actions.
- **Professor**: approves academic depth, copyright/attribution, assessment validity and release.

## Per-session deliverables
1. Outcome-aligned session brief and 3-hour teaching run sheet (separate online/campus adaptations).
2. Structured lecture source and PPTX draft, with examples/visuals and slide-by-slide instructor notes.
3. Colab-compatible student lab, dependencies, datasets and instructions.
4. Instructor lab solutions in **private** storage only; do not commit to this public repo.
5. Exercises, extension exercise, reading/reference links and citation provenance.
6. Automated QA report and professor approval.

## Release gates
- LO coverage and approved scope checked; bibliography items verified, no fabricated citations.
- Student notebooks execute cleanly and deterministically in a clean environment; no embedded answers.
- PPTX editable, opens correctly, legible at screen-sharing resolution; equations checked.
- Online participation/fallback and on-campus activity instructions exist.
- Privacy, data licenses, accessibility, instructor-only content and release destinations verified.

## Sequence
Phase A: approvals and course architecture → Phase B: skills/templates/CI → Phase C: two pilots (S01 online and S02 campus) → Phase D: remainder batches → Phase E: assessment packages and release validation.
