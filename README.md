# M5 Machine Learning — MSc Computer Science

A simple, session-based teaching repository for the Ascencia Malta MSc Machine Learning module (MQF Level 7, 10 ECTS).

## Course at a glance

- 16 sessions × 3 hours; working hybrid allocation: 9 online and 7 on campus.
- Approved learning outcomes: LO1–LO8.
- Assessment: written examination 60%, Kaggle capstone 30%, presentation 10%.
- The official module descriptor remains authoritative. Do not reinterpret assessment rules or institutional decisions.

## Start here

1. [Course plan](course-plan.md) — the teaching overview and session sequence.
2. [Course status](COURSE_STATUS.md) — a concise record of what exists and what still needs professor verification.
3. [Sessions](sessions/) — materials grouped by S01–S16. Each session can contain a README, lecture, slides, exercises and Colab notebook.
4. [Course-builder skill](skills/msc-course-builder/SKILL.md) — optional Codex instructions for preparing a session.

Historical detailed curriculum, delivery plans, reference data, templates and validators are retained for traceability; they are **optional reference material**, not administrative gates for everyday teaching.

## Simple working method

Work directly on `master`: choose a session, read its material, edit or create the necessary teaching resources, check academic accuracy and notebook execution, then commit and push. **No GitHub Project Board, issue, feature branch or pull request is required.** An issue or PR can still be used voluntarily for exceptional collaboration, but is never a prerequisite.

Keep the student-facing package easy to navigate: `README.md`, `lecture.md`, `slides.md`/`slides.pptx`, `exercises.md`, and `student-lab.ipynb` or `lab.ipynb`. Existing files in S01 stay in place; migrate only when necessary, without discarding teaching content.

## Public repository safety

This repository is public. Do not commit identifiable student information, marks, private correspondence, unreleased examination questions or keys, instructor-only solutions, or unlicensed material. Check scholarly citations and accessibility before publishing.
