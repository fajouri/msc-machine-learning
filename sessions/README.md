# Teaching sessions

Each Sxx folder contains the teaching materials for one 3-hour session. Use `course-plan.md` and `COURSE_STATUS.md` at repository root to locate the working sequence and track progress.

Suggested session files: `README.md` (guide), `lecture.md` (detailed notes), `slides.md` and editable `slides.pptx`, `exercises.md`, and `student-lab.ipynb` (Colab) where relevant. Older session files are valid and need not be renamed just for consistency.

Use the `msc-course-builder` skill for academic drafting. Check the outcomes and examples, update the status, and commit to `master`; no board, issue or PR is needed.
